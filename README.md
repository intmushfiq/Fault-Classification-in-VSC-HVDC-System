# Fault-Classification-in-VSC-HVDC-System
This repository contains the complete work for a VSC-HVDC fault diagnosis study carried out as an EEE 306 (Power System I Laboratory) project at BUET. A two-terminal ±100 kV VSC-HVDC link was modelled in MATLAB/Simulink to generate AC faults (LG, LL, LLG, LLL at both stations) and DC line faults at five positions, across ten fault resistances and 48 RMS time windows per scenario. The resulting datasets were used to train and compare ANN, Random Forest, and 1D-CNN classifiers, along with a three-stage hierarchical pipeline (Normal → AC/DC → specific fault type), plus four regression models for DC fault location. Repository contents: the Simulink model and MATLAB data-extraction scripts, the classification and location datasets, Jupyter notebooks for all models, and the full project report.
